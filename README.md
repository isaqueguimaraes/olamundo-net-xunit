# Projeto Hello World - Testes Unitários

Repositório criado para a atividade da disciplina de Garantia da Qualidade de Software.

## 🛠️ Tecnologias Utilizadas
- Java 21 / OpenJDK
- Maven
- JUnit

## 📌 Descrição
Implementação de testes unitários simples para validação do método de saudação da classe `Hello`/`OlaMundo` utilizando a estrutura de assertividade do JUnit.
